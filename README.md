# HideApps

Ẩn mọi cửa sổ app trên Windows 10/11 bằng một phím tắt, bấm lần nữa để hiện lại.
Hide every app window on Windows 10/11 with one hotkey, and press it again to bring them back.

**Tải về / Download:** xem mục [Releases](https://github.com/dacthinh05/HideApps-releases/releases/latest).

Repo này chỉ chứa file phát hành. `latest.json` cho app biết phiên bản mới nhất.
This repository only holds release files. `latest.json` tells the app which version is the newest.
