# HideApps

Ẩn mọi cửa sổ app trên Windows 10/11 bằng một phím tắt, bấm lần nữa để hiện lại.
Hide every app window on Windows 10/11 with one hotkey, and press it again to bring them back.

## Tải về / Download

- **[Tải bộ cài HideApps-Setup.exe](https://github.com/dacthinh05/HideApps-releases/releases/latest/download/HideApps-Setup.exe)** (nên dùng): tải về rồi chạy, không cần quyền Admin.
  [Download the setup program](https://github.com/dacthinh05/HideApps-releases/releases/latest/download/HideApps-Setup.exe) (recommended): run it after downloading; no admin rights needed.
- [Bản chạy ngay HideApps.zip](https://github.com/dacthinh05/HideApps-releases/releases/latest/download/HideApps.zip): giải nén rồi chạy `HideApps.exe`, không cần cài.
  [Portable HideApps.zip](https://github.com/dacthinh05/HideApps-releases/releases/latest/download/HideApps.zip): extract it and run `HideApps.exe`, nothing to install.
